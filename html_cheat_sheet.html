HTML Cheat Sheet


Body Tags

Element Description Code Example
<html> Defines the root of the HTML document <html> . . . </html>
<head> Contains the meta-information about an HTML document <head> . . . </head>
<body> Contains the content of an HTML document <body> . . . </body>
<title> Sets the title of the webpage, seen in the browser tab <title>My Awesome Website</title>
<link> Link CSS files to your HTML page <link rel="stylesheet" href="styles.css">
<script> Link JS scripts to your HTML page <script src="script.js"></script>

Formatting

Element Description Code Example
<p> Paragraph for text <p>This is my example text! It can be as long as you want.</p>
<h1> Header. Scales from 1-9 in order from biggest to smallest <h1>This is my header!</h1>
<br> Creates a line break Line 1 <br> Line 2
<div> Divides and organizes HTML code <div class="tag"> . . . </div>
<span> Inline text block <span class="tag">This is my text block!</span>

Text Tags

Element Description Code Example
<b> Bold text <b>This is my bold text!</b>
<strong> Defines text with strong importance, typically in bold <strong>THIS IS MY IMPORTANT TEXT!</strong>
<em> Italic text <em>This is my italic text!</em>
<sub> Subscript text <sub>This is my subscript text!</sub>
